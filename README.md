# 🌤️ Weather Forecast App

A Flutter-based weather forecast application that provides dynamic weather information, location search, and forecast details through a clean and user-friendly interface.

## ✨ Features

- 🌦️ Dynamic weather data
- 📍 Location search
- 🌡️ Current weather information
- 📅 Weather forecast
- 🔄 Refreshable weather information
- 📱 Responsive Flutter UI
- 🧭 Location-based weather support
- 💾 Local data support where implemented in the app

## 🛠️ Technologies Used

- **Flutter**
- **Dart**
- **REST API**
- **Android Studio**
- **Git & GitHub**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hina73899-ai/weather-forecast-app.git
```

### 2. Open the project

Open the project in **Android Studio** or **VS Code**.

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

Connect an Android device/emulator and run:

```bash
flutter run
```

## 🔑 API Configuration

This application uses a weather API to retrieve dynamic weather information.

If the project uses an API key, configure the key according to the API configuration used in the project before running the application.

> Never commit private API keys or other secrets to a public GitHub repository.
